TEMO DESIGN SYSTEMWelcome to the TEMO Design System documentation repository. This repository serves as the authoritative, single source of truth for the visual identity, spatial environment, component architecture, kinetic motion, user experience, and technical integration of TEMO AI OS.  The purpose of this documentation system is to provide a cohesive design architecture that bridges creative direction and software implementation. It is designed to be used by designers, frontend engineers, and AI coding agents to ensure pixel-perfect fidelity, operational consistency, and fluid motion across all UI/UX surfaces.  The files in this repository function as an interconnected, modular network: visual character concepts and environment lighting inform spatial layouts, component specifications translate spatial rules into scalable UI primitives, and backend mapping links frontend states to operational data engines. The Assets/ folder supports this framework by housing central visual reference materials, token exports, design mockups, and static graphic files required during build-time development. All future UI/UX implementations, components, and layout updates must strictly adhere to the guidelines established within these documents. Source of TruthThis documentation must be treated as a unified, immutable system. All future designers, AI coding assistants, and frontend developers are required to follow these specifications consistently without unauthorized deviation. Any updates or additions to the user interface must be documented and reconciled across the entire file architecture to maintain systemic integrity.  Implementation RuleThe specifications in this design system define the intended UI/UX behavior, kinetic motion, and visual identity of the system. The existing TEMO AI OS backend infrastructure remains the sole authoritative source for application functionality, business logic, agent orchestration, and live data management. Frontend implementations must interface cleanly with established backend patterns while maintaining strict compliance with this design specification.
